# Studio Clips

Transforme une longue vidéo en clips TikTok : transcription (Whisper), choix des passages et montage au chat (IA locale Ollama), sous-titres karaoké, export 1080×1920. Tout tourne sur le PC.

**Installer** : télécharger [Studio-Clips.exe](../../releases/latest/download/Studio-Clips.exe) et double-cliquer.
Les mises à jour s'installent seules à chaque lancement.

Publier une version : `.\outils\publier.ps1 -Notes "ce qui change"`.
